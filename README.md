# Interfacing L2410C with WEMOS D1 Mini and Tasmota

How to configure a radar presence sensor LD2410C with WEMOS D1 Mini (ESP8266) using Tasmota Firmware. This repository is for documentation how we use Tasmota to monitoring a distance between a human with sensor.

## 🔨 Hardware
1. Wemos D1 Mini
2. LD2410C Sensor
3. Jumper Cable
4. Breadboard or PCB Dot Matrix
5. Laptop

## 💻 Software 
1. Tasmota Documentation : [Click Here](https://github.com/arendst/Tasmota/releases)
2. Google Chrome/Edge
3. MQTT Broker (Optional)
4. Visual Studio Code/Notepad++/Any Favorite Text Editor
